# @deepseek-ai/dsh-experimental-client-ui-next-step

English | [中文](README.zh.md)

## Summary

The browser half mounts the predictor's Remote stream once, watches every Session in the list, and stages each snapshot through `ctx.composerSuggestions.set`. The Conversation composer renders that text as ghost text while its draft is empty; Tab accepts it, any draft hides it, and clearing the draft brings it back. Predictions are generated by the [Host package](../next-step/README.md).

<a id="use-this-package"></a>
## Use this package

Mount it beside the Conversation plugin in the same Web profile. It injects `remote`, `sessions`, and `composerSuggestions`, so the matching Host entry and `ui-conversation` must already run:

```yaml
- name: '@deepseek-ai/dsh-experimental-client-ui-next-step'
```

No configuration; the Host decides which Sessions predict.

<a id="understand-the-implementation"></a>
## Understand the implementation

`apply` mounts the generated Remote contribution, subscribes to the Session list, opens one `watch` stream per listed Session, and closes the stream when its Session leaves the list or the plugin unloads. Each snapshot replaces that Session's staged suggestion; an empty text clears it. Watch failures are logged and do not disturb the composer.

## Model Experience

None, as the browser half only stages the Host's prediction as unsent draft text.

#### KV Cache effect

No effect; the browser sends no model request.

## Known Limitations and Deferred Work

- **Every listed Session streams.** Each entry holds an open Remote stream even when the human is elsewhere; a focused-Session subscription would be cheaper.
- **No dismissal.** The suggestion stays staged until a new prediction, a send, or a Session switch; the browser has no way to reject one.
